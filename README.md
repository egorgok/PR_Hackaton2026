# Media Monitoring Backend

Асинхронный FastAPI-прототип для поиска свежих публикаций на публичных страницах редакций
Красноярского края. Исходный реестр редакций и URL площадок взят из `sources.xlsx`.

## Запуск

Требуется Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
uvicorn app.main:app --reload
```

Swagger UI: `http://127.0.0.1:8000/docs`

## API

`GET /sources` отдаёт доступный каталог редакций и площадок. Создание поиска:

```json
POST /jobs
{
  "text": "Пожар в школе Красноярска",
  "platform": ["website", "telegram", "vk"],
  "editor": ["Авангард", "Ангарская правда"],
  "days": 7
}
```

Поддерживаемые `platform`: `website`, `max`, `telegram`, `vk`, `ok`, `zen`. Период: `1`, `3`,
`7`, `14` или `30` дней. Редакция и URL разрешаются только по реестру; несуществующий адрес
не подменяется догадкой.

Создание возвращает `job_id` и `status_url`. Фронтенд опрашивает `GET /jobs/{job_id}` примерно
раз в 2 секунды. Ответ содержит `status`, `processed_sources`, `total_sources`, текущие статусы
источников и инкрементально добавляемые `results`. Когда задача завершена, XLSX доступен по
`GET /jobs/{job_id}/export.xlsx`. Пустые результаты отличаются от недоступных источников.

Публикация включает редакцию, платформу, заголовок, прямую ссылку, выдержку, дату и `date_status`.
Для поискового периода в результаты включаются только материалы с извлечённой датой внутри периода.
Кандидаты без даты не включаются; их число возвращается в `excluded_undated_count` и `undated`
источника со статусным пояснением.

## Сбор и отбор

- Обычные сайты: HTML, schema.org/metadata, ссылки со страницы редакции и RSS/Atom, если он
  объявлен в HTML. Навигационные/тематические разделы не считаются статьями; страница должна
  иметь признаки article/NewsArticle или публикационную микроразметку. Кандидат считается
  результатом только после проверки даты и содержания; ссылка сохраняется прямой.
- Telegram: публичный HTML preview `t.me/s/...`; результаты зависят от доступности preview.
- VK, Одноклассники, MAX и Дзен: попытка читать публичную HTML-разметку без авторизации. Эти
  платформы часто меняют клиентскую разметку или требуют входа; парсеры намеренно не обходят
  авторизацию, CAPTCHA, антибот-защиту и rate limits.
- Лексический fallback извлекает ключевые слова из запроса, нормализует распространённые русские
  окончания и требует совпадения минимум двух значимых слов, если их больше одного. Это
  эвристика, не полноценная русская морфология: сложные словоформы и пересказы могут быть
  пропущены; при настроенном GigaChat используется смысловой отбор.
- Если задан GigaChat, найденные тексты пакетно передаются модели для проверки смысловой связи
  и перефразированных версий. При сбое модели используется лексический отбор, а сбой записывается
  в `errors`. Ключевые слова и правила не являются доказательством релевантности.
- Повтор URL в рамках задания учитывается один раз. Разные URL размещения одной новости считаются
  отдельно.

Один сетевой запрос к списку выбранных редакций может превышать минуту. Задания продолжаются до
завершения; на длительность влияют количество источников, доступность страниц и ответы GigaChat.
Текущие задания и результаты хранятся в памяти процесса, поэтому перезапуск сервера удалит их.
Для демонстрации запускайте один worker; для постоянной эксплуатации нужны очередь и общее
персистентное хранилище.

## GigaChat

Копируйте `.env.example` в `.env` и заполните `GIGACHAT_AUTH_KEY`; адреса auth/API и scope можно
переопределить переменными окружения. `.env` исключён из Git. Получите разрешённый для вашего
аккаунта ключ в кабинете Sber, не добавляйте секрет в исходники и не передавайте его фронтенду.
Без ключа приложение работает в lexical-only режиме. Доступ модели, лимиты и стоимость зависят
от выданного аккаунту тарифа; перед демонстрацией проверьте его самостоятельно.

При настроенной модели публичный запрос пользователя и извлечённые фрагменты публикаций
отправляются в GigaChat. Не включайте в запросы закрытые или персональные данные.

## Ограничения и достоверность

Сбор без API не гарантирует доступ к площадке, полный охват ленты или заданную задержку. HTTP 403,
429, CAPTCHA и неподдерживаемый HTML отражаются статусом источника; остальные источники и
частичные результаты сохраняются. Обход защит не выполняется. Список URL в таблице не означает,
что все эти страницы доступны для автоматического чтения. Перед демонстрацией проверяйте выбранные
источники вручную и показывайте их фактические статусы, а не заранее сохранённые результаты.
